## 夏目安安表情包制作器
```bash
用法: [-t 文本] [-i 图片名称] [-f 表情索引] [-o <图片名称>]
示例:-t "你想加入的文本" -i input.png -f 6 -o out.png
选项:
	-t <文本>	安安笔记本上的内容
	-i <图片>	安安笔记本上的图片
	-f <表情>	安安的表情(数字)
	-o <图片>	安安
表情索引:
	0 = 高兴
	1 = 平常
	2 = 病娇
	3 = 脸红
	4 = 愤怒
	5 = 无语
	6 = 傲娇
	7 = 高兴_q版
	8 = 傲娇_q版
	9 = 默认_q版
注意:
	1.添加图片和文本后, 若缺少文本, 推荐换行或减少字数
	2.文字有概率重叠, 可以通过多次生成调整;若多次重叠则减少字数
	3.部分表情无法容纳太多字。据目前所知, 最少仅容纳两个字或4个英文字母
	4.换行符:英文标点、空格
```
