## 夏目安安表情包制作器
```bash
用法: [-t 文本] [-i 图片名称] [-f 表情索引] [-o <图片名称>]
示例:-t"你想加入的文本" -i input.png -f6 -o out.png
选项:
	-t <文本>	安安笔记本上的内容
	-i <图片>	安安笔记本上的图片
	-f <表情>	安安的表情(数字)
	-o <图片>	安安

	-r<角度> 旋转安安
表情索引:
	0 = 高兴
	1 = 平常
	2 = 病娇
	3 = 脸红
	4 = 愤怒
	5 = 无语
	6 = 若叶睦
	7 = 希罗
	8 = 傲娇
	9 = 全身
换行符:空格
```
